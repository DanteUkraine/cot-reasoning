# Changelog

All notable changes to the cot-reasoning skill are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/); versioning is semantic.

## [6.0.0] — 2026-10-15

### Changed
- **FSM routing architecture**: the numbered 10-step workflow is replaced by a
  strict Finite State Machine router (`observe → reason → act → verify →
  report`) that preserves the ReAct loop as four distinct, uncompressed
  states; every transition names its mandatory gate and the unit where its
  logic unfolds
- **Native cognition delegation**: a `<cognitive_protocol>` unit routes all
  live reasoning — FSM rule processing and next-state transition planning —
  into the model's native `<|think|>` channel; the skill defines no custom
  thought tags. The simulated self-dialogue monologue is no longer defined in
  SKILL.md; it remains a mode-conditional display scaffold in the
  self-dialogue template (BASIC/STANDARD). The `**Thought:**` step field is
  documented as an audit artifact (still required by the validator in
  BASIC/STANDARD)
- **Shift-Left QA**: `<step_gates>` and `<quality_gate>` merged into a single
  12-row `<verification_gate>`; the `act → report` transition is impossible
  without every row passing on raw artifact evidence (CLI exit codes, log
  outputs, test results); unrunnable checks are recorded UNVERIFIED, never
  passed

### Added
- `references/reasoning-disciplines.md`: full discipline procedures extracted
  from SKILL.md (Tier 3 context economy; SKILL.md 433 → 380 lines)
- `<references>` inventory in the `| When Condition Fires | File Path | Tag Anchor |` format

### Fixed
- Reference headers that cited numbered workflow steps ("step 2/3/7 of
  SKILL.md") now cite FSM states
- Literal `<|think|>` pipes inside markdown table cells escaped as `<\|think\|>`
  so the tables remain parseable

## [5.2.0] — 2026-10-03

### Added
- **Externalized reasoning disciplines** — five mode-conditional disciplines that
  replace capabilities a weak reasoner lacks with external procedure:
  - Contract Formalization (STANDARD/ENHANCED): open-ended statements are closed
    into measurable contracts before decomposition
  - Typed Step Outputs (BASIC and up): step outputs are typed structures with a
    regeneration micro-loop on violation (`Output Schema` step field)
  - Verification Loop (STANDARD/ENHANCED): failed verification iterates on raw
    captured evidence with a declared budget (`Max Iterations`, `Exit Criteria`,
    `Escalation Policy` — always as a set)
  - Confidence Gate (BASIC and up): confidence becomes an action gate
    (default threshold 7.0/10), no silent pass
  - Edge Coverage (STANDARD/ENHANCED): validation cases derived by covering
    state/transition graphs instead of intuition
- **Self-confirmation protocol**: gate rule 4 extended to produced artifacts
  (expected values derive from the original contract, never from the artifact);
  new rule "verify the computed result, not the written text"; behavior-first
  validation principle
- **Instruction-type taxonomy** at step 0 (Direct / Task-specific / Open-ended);
  open-ended requests trigger formalization
- **Fast-fail discipline** in verification loops: a stalled check hands partial
  evidence to the loop instead of consuming the budget
- **New step types** in the step-execution template: Contract Formalization Step,
  Verification Loop Step, Edge-Case Derivation procedure
- **Verification Loop Iteration** self-dialogue pattern
- **Operating rules for weak reasoners** in model-capabilities.md: instantiate
  the closed vocabulary; plan-then-execute
- **Fifth example flow** (`intermittent-batch-failure-investigation`) demonstrating
  all five disciplines
- **Test infrastructure**:
  - Regression suite: 17 fixtures + expectations manifest + 5 built-in CLI cases
    (22 cases, 99% of validator check templates covered)
  - Consistency lint: version alignment, frontmatter validity, cross-references,
    universality guard (no domain-specific terms in skill content)
  - Behavioral eval harness: 10 reference prompts with expected profiles, scorer
    producing a pass-rate matrix; first measured data point (Mistral Vibe agent:
    validator 10/10, profile 10/10)
  - CI workflow (GitHub Actions): example validation, regression suite, lint,
    advisory shellcheck

### Fixed
- Version drift: the output contract emitted `Generated By: v5.1.0` while the
  validator required `v5.0.0`; all artifacts now state one version consistently
- Validator script was not executable
